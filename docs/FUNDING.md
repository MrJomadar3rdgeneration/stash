# Supporting Stash

Stash will remain free and open source. Feedback, testing, documentation, and code contributions are valuable ways to help; financial support is optional.

The first funding milestone is **$99 per year for the Apple Developer Program**. That membership provides the Developer ID certificate and notarization access needed to distribute a normal downloadable Mac app that macOS can verify.

Until a public contribution channel is configured, the best way to help is to try the supported source installer, report reproducible problems with fictional data, and share thoughtful feedback. When funding becomes available, this page and the repository's funding link will name the provider and explain how funds are used.

Funding the membership will enable signed and notarized downloads. It will not change Stash's MIT license, local-first design, or free availability.
